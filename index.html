Doc → Markdown

Thả file PDF, DOCX hoặc PPTX vào đây để nhận lại file .md. Mọi thứ chạy ngay trong trình duyệt, file không được tải lên server nào và không giới hạn dung lượng.

Kết quả

    PDF: lấy lớp chữ có sẵn, bản scan cần OCR trước. DOCX/PPTX: chỉ định dạng Office 2007+, file .doc/.ppt cũ hãy lưu lại thành .docx/.pptx. Ảnh không được đưa vào file md.
